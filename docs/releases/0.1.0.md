Initial ContentRefiner SDK and one shared SwiftCrossUI comparison app.

The public SDK and Core have no UI dependency. ContentRefinerBase owns reusable comparison components, app state, provider settings and history. Thin Mac/Linux/Windows packages share it and have independent versions/artifacts.

Includes iterative original/current anchoring, consolidated instructions, variations, issue/change reporting, ordered fallback, cooperative timeouts, cancellation and raw response preservation. AgentAtom typed execution and installed CLI/on-device providers are available on Mac; configured HTTP providers work across platforms.

Mac app requires macOS 26+ and is ad-hoc signed, not notarized. Linux needs GTK 4 runtime. Windows needs matching Windows App Runtime for SwiftCrossUI's WinUI backend. See README and Packages/README.md for integration/build/runtime requirements.
